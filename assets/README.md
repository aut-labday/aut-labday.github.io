# AUT Lab Day download assets

The website expects the official 2025 A2 poster PowerPoint template at:

`assets/Labday_IPK_IWF_Postervorlage_A2_mit_Steckbrief.pptx`

The file is the original 7-layout A2 portrait poster template supplied by the organizers. Upload the **original PPTX without renaming it** (GitHub web interface: Add file → Upload files, inside this folder). Once uploaded, the download button in the **Studierende / HiWis** instructions automatically becomes visible on the next page load.

This GitHub connection can create and edit text files but cannot upload binary PPTX attachments. Only publish institutional template files once their public distribution has been approved.

Do not upload completed student posters, unpublished research slides, or personal data to this public website.
